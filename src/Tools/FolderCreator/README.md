# FolderCreator 使用说明

> WinToolBox 子工具：用一段「短横线缩进」文本描述文件夹层级，一次性**批量创建文件夹结构**，也可以**检查现有目录是否符合规则**。

[← 返回 WinToolBox 总览](../../../README.md)

- 程序名：`FolderCreator.exe`（WinForms 桌面程序，C# / .NET 8）
- 项目位置：`src/Tools/FolderCreator/`，引用共享库 `src/WinToolBox.Core` 并复用其中的 `Logger`

## 运行要求

| 使用方式 | 要求 |
| --- | --- |
| 源码运行 | Windows 10 / 11（x64）+ .NET 8 SDK |
| 单文件 exe | Windows 10 / 11（x64），双击 `FolderCreator.exe` 即可；发布包自包含 .NET 运行时，**免安装、无需预装 .NET** |

下载：打开 <https://github.com/zhiyuebin/WinToolBox/releases/latest>，下载 **`FolderCreator-win-x64.zip`**，解压到任意目录后双击其中的 `FolderCreator.exe`。

## 快速上手（5 步）

1. **启动**：运行 `FolderCreator.exe`；从源码调试则执行 `dotnet run --project src/Tools/FolderCreator/FolderCreator.csproj`。
2. **选根目录**：在顶部文本框填写目标目录，或点「浏览…」选择——所有文件夹都会创建在这个根目录下。
3. **粘贴规则**：在左侧规则框粘贴短横线层级文本；不确定格式时点「载入示例规则」填入一份可直接运行的示例。
4. **选模式**：检查时选择 **严格模式**（默认，会报出「多余」）或 **宽松模式**（只报「缺失」）。
5. **执行**：「创建文件夹」开始批量创建，「检查一致性」对比目标目录；结果显示在右侧结果树，进度与提示显示在底部状态栏。

## 规则语法

用行首连续的 `-` 表示层级：1 个 `-` 为第一级，`--` 为第二级，`---` 为第三级，以此类推。

```text
# 这是一个注释行，以 # 开头将被忽略
根目录名称

-一级目录
--二级目录
---三级目录
-一级目录2
--二级目录2
```

解析规则：

| # | 规则 | 说明 |
| --- | --- | --- |
| 1 | `-` 的个数 = 层级深度 | 1 个 `-` 为第一级，`--` 为第二级，最多 32 级 |
| 2 | 短横线后的空格可省略 | `-一级目录` 与 `- 一级目录` 等价，前导空格会被去掉 |
| 3 | `#` 开头的行为注释 | 整行忽略，可写说明文字 |
| 4 | 行首没有 `-` 且不是 `#` 的行被忽略 | 例如 `根目录名称`，可当作根目录提示书写，不参与创建 |

上面的示例会创建：`一级目录\二级目录\三级目录` 与 `一级目录2\二级目录2`。

## 父级自动补齐与名称校验

- **父级自动补齐**：如果出现 `---三级目录` 而前面没有 `--二级目录`，解析器会**自动补齐缺失的父级**，补齐出来的目录名固定为 **`未命名目录`**，并在界面上给出**带行号的警告**。请按警告提示回到规则里把 `未命名目录` 改成你想要的名称。
- **非法字符校验**：目录名不能包含以下内容，否则解析阶段直接报错并列出「第 N 行」，此时**不会执行创建**：
  - 非法字符：`\`、`/`、`:`、`*`、`?`、`"`、`<`、`>`、`|`
  - Windows 保留设备名：`CON`、`PRN`、`AUX`、`NUL`、`COM1`~`COM9`、`LPT1`~`LPT9`
  - 目录名不能以 `.` 或空格结尾
  - 单个层级最长 255 个字符，层级最深 32 级

## 创建文件夹

- 在所选根目录下用 `Directory.CreateDirectory` 递归创建，**父级目录自动创建**。
- **已存在的文件夹直接跳过、不报错**，只创建缺失的部分，可重复执行。
- 创建过程在**后台线程**执行，界面不会卡死，底部有进度条与状态提示。
- 失败**逐条捕获**：权限不足、路径过长、非法字符等都会给出友好提示，失败项在结果树中标红，其余目录继续创建。

## 检查一致性

选择目标根目录后点「检查一致性」，结果用树形结构展示并着色：

| 状态 | 含义 | 颜色 |
| --- | --- | --- |
| **匹配** | 规则里有，目标目录里也有 | 绿色 |
| **缺失** | 规则里有，目标目录里没有（创建失败同样标红） | 红色 |
| **多余** | 目标目录里有，规则里没有（仅严格模式） | 黄色 |
| **已存在（跳过）** | 创建时目录已存在，直接跳过 | 灰色 |

| 检查模式 | 行为 |
| --- | --- |
| **严格模式**（默认） | 除「匹配 / 缺失」外，还报出目标目录里多出的文件夹（「多余」） |
| **宽松模式** | 只检查规则要求的文件夹是否存在，忽略多出的文件夹 |

## 命令行参数

```powershell
# 查看版本
FolderCreator.exe --version

# 本机冒烟自检：在临时目录里跑一遍「解析规则 → 生成目录 → 重复生成（应全部跳过）→ 检查一致性（严格/宽松）」，
# 仅用于本机自检，不需要真实数据；退出码 0 表示通过（不加路径时报告写到 %TEMP%\FolderCreator-selftest.txt）
FolderCreator.exe --selftest
FolderCreator.exe --selftest D:\selftest-report.txt   # 同时把报告写到指定文件
```

## 日志

FolderCreator 复用 WinToolBox 共享日志组件，日志写入：

```text
%LocalAppData%\WinToolBox\logs\wintoolbox-yyyyMMdd.log
```

（通常为 `C:\Users\<用户名>\AppData\Local\WinToolBox\logs\`，与 UsbBackup 共用同一日志文件，按天切割。）

## 常见问题

| 问题 | 原因与处理 |
| --- | --- |
| 为什么我的某一行没有被创建？ | 该行**行首没有 `-`**（会被当成根目录提示忽略）或**以 `#` 开头**（注释行）。请给需要创建的行加上对应数量的 `-`。 |
| 为什么出现了 `未命名目录`？ | 规则里跳级了（例如直接写 `---三级目录` 而缺少 `--二级目录`），解析器自动补齐父级，补齐出来的名字就是 `未命名目录`。按警告的行号把父级补全即可。 |
| 检查报了一堆「多余」怎么办？ | 目标目录里存在规则未描述的文件夹。若这些文件夹是正常的，改用**宽松模式**只检查缺失；若确实不该存在，到目标目录中删除后重新检查。 |
| 创建时报权限不足 / 路径过长？ | 换一个当前用户有写权限的根目录，或缩短目标路径（Windows 默认路径长度上限约 260 个字符）；失败原因会逐条显示在结果树与状态栏，并写入日志。 |
