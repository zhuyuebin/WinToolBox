# UsbBackup 使用说明

> WinToolBox 子工具：把 U 盘**增量备份**到本地硬盘的指定目录。插上 U 盘后**手动点「立即备份」**，程序不做任何自动拷贝。

[← 返回 WinToolBox 总览](../../../README.md)

| 项目 | 内容 |
| --- | --- |
| 程序名 | `UsbBackup.exe`（WinForms 窗口程序 + 常驻托盘图标，C# / .NET 8） |
| 项目位置 | `src/Tools/UsbBackup/`（输出 `UsbBackup.exe`） |
| 版本 | `0.1.0`，统一由仓库根 [`Directory.Build.props`](../../../Directory.Build.props) 控制 |
| 共享库 | 引用 `src/WinToolBox.Core`，复用其中的 `Logger` / `ConfigManager` / `FileCopier` / `UsbDetector` / `Notifier` |

## 运行要求与获取方式

| 使用方式 | 要求 |
| --- | --- |
| 单文件 exe（推荐） | Windows 10 / 11（x64），双击 `UsbBackup.exe` 即可；发布包自包含 .NET 运行时，**免安装、无需预装 .NET** |
| 从源码运行 | Windows 10 / 11（x64）+ .NET 8 SDK：`dotnet run --project src/Tools/UsbBackup/UsbBackup.csproj` |

下载：打开 <https://github.com/zhiyuebin/WinToolBox/releases/latest>，下载 **`UsbBackup-win-x64.zip`**，解压到任意目录（例如 `D:\Tools\UsbBackup\`），双击其中的 `UsbBackup.exe`。

- **免安装**：不写注册表、不注册系统服务，只在自己的用户目录下写配置文件与日志。
- 首次运行可能被 SmartScreen 拦截（程序未做代码签名）：点「更多信息」→「仍要运行」即可；单文件程序首次启动会自解压到临时目录，属正常现象（见[常见问题](#常见问题)）。

## 快速上手（5 步）

1. **启动**：双击 `UsbBackup.exe`。程序会**直接打开主界面窗口**，同时在通知区域（任务栏右下角）放一个常驻托盘图标；Windows 11 默认把新图标收进 **“^” 折叠区**。
2. **选目标目录**：在「备份设置」里填写或点「浏览…」选择**备份目标目录**（建议选本地硬盘上的一个空目录，**不要选 U 盘自身**）。
3. **按需改排除项**：在「排除的文件后缀」里用英文逗号追加不想备份的后缀（例如 `.iso,.zip`），然后点「保存设置」——不点保存不会生效。
4. **插好 U 盘并手动备份**：点「立即备份」（或托盘右键 →「立即备份」）。程序会对**当前所有已插入**的 U 盘各做一次增量备份；完成后弹托盘气泡，结果同时写进「运行日志」。
5. **查看与退出**：备份文件在 `{目标目录}\{卷标}_{卷序列号}\{yyyy-MM-dd}\`；点「打开日志目录」可查看日志。**关闭窗口只会最小化到托盘**，要彻底退出请点「退出程序」或托盘右键「退出」。

## 主界面说明

窗口标题为 `WinToolBox - U盘备份`，从上到下分成四块：

| 分区 | 控件 | 说明 |
| --- | --- | --- |
| 备份设置 | 「备份目标目录」文本框 | 显示当前配置的备份目标目录，可直接编辑 |
| 备份设置 | 「浏览…」 | 弹出文件夹选择框挑选目标目录；选完需点「保存设置」 |
| 备份设置 | 「排除的文件后缀」文本框 | 英文（也接受中文）逗号分隔的后缀，如 `.tmp,.part`；保存时会统一成小写并补 `.` |
| 备份设置 | 「保存设置」 | 写入配置文件并把规范化结果回填界面；目标目录为空时会提示「请先选择备份目标目录」，不保存 |
| 操作 | 「立即备份」 | 手动触发备份的两个入口之一（另一个是托盘右键「立即备份」）。备份期间按钮禁用、鼠标变等待，重复点击会被忽略；只有复制，绝不执行 U 盘里的任何程序 |
| 操作 | 「刷新设备」 | 重新枚举可移动磁盘，状态栏提示「已检测到 N 个 U 盘」或「未检测到 U 盘」 |
| 操作 | 「打开日志目录」 | 用资源管理器打开 `%LocalAppData%\WinToolBox\logs\` |
| 操作 | 「隐藏到托盘」 | 只隐藏窗口，程序继续常驻，双击托盘图标可回来 |
| 操作 | 「退出程序」 | 二次确认后真正退出（结束进程、移除托盘图标） |
| 操作 | 「设备：N 个」 | 当前检测到的可移动磁盘数量 |
| 运行日志 | 日志文本框 | 实时滚动显示日志（含异常堆栈）；打开窗口时先回显当天日志**末尾最多 100 行**；界面最多保留 800 行，超出后从最前面裁掉 |
| 运行日志 | 「清空」 | 只清空界面文本，**不影响**磁盘上的日志文件 |
| 底部 | 状态栏 | 显示「就绪」「正在备份…」「备份完成：成功 N 个，跳过 M 个，失败 K 个」等提示 |

## 托盘菜单

在托盘图标上**右键**打开菜单（左键单击无动作，**左键双击 = 打开主界面**）：

| 菜单项 | 作用 |
| --- | --- |
| **打开主界面** | 显示并激活主窗口（**双击托盘图标**效果相同；点击气泡通知效果也相同） |
| **立即备份** | 对所有已插入的 U 盘各执行一次增量备份；已有备份在跑时提示「备份正在进行」，不会重复排队 |
| **打开日志** | 用资源管理器打开日志目录 `%LocalAppData%\WinToolBox\logs\`，再双击当天的 `wintoolbox-yyyyMMdd.log` |
| **退出** | 停止 U 盘监听并退出程序（不会驻留后台进程） |

> 托盘图标文字为 `WinToolBox - U盘备份`。**关闭主窗口 = 最小化到托盘**（首次会弹一次气泡「已最小化到托盘，双击托盘图标可重新打开。」），程序继续常驻，直到你点「退出程序」或托盘右键「退出」。

## 备份规则

### 目标路径模板

```text
{配置的目标目录}\{卷标}_{卷序列号}\{yyyy-MM-dd}\
```

例如目标目录 `D:\UsbBackup`、卷标 `MYUSB`、卷序列号 `1A2B3C4D`，2026-09-30 这次备份写入 `D:\UsbBackup\MYUSB_1A2B3C4D\2026-09-30\`。

- 设备用**卷标 + 卷序列号 + 容量**识别，**不使用盘符**（换 USB 口后盘符会从 `E:` 变成 `F:`，备份仍落在同一个设备目录里）。
- 每天一个日期目录，历史备份不会被新备份覆盖。
- 卷标为空用 `NOLABEL` 占位，序列号读不到用 `00000000` 占位；卷标里的非法字符会替换成 `_`。

### 增量策略

- **只复制，不删除**：程序**永远不会删除**目标目录里的任何文件，也不改动 U 盘上的任何内容。
- **未修改的文件跳过**：按「**修改时间 + 大小**」判断，大小相同且目标不比源旧即视为未修改。
- 只复制**新增文件**和**已修改文件**；复制后把目标文件的修改时间对齐源文件，保证下次判断准确。
- U 盘上已删除的文件，在备份目录里**依然保留**（历史快照语义，不做同步删除）。
- 单个文件失败不会中断整轮备份：日志会记录失败数量与前 5 条明细，界面汇总为「失败 K 个」。

### 默认排除项

以下内容默认不参与备份（避免把系统垃圾与自动播放脚本带进备份）：

| 类别 | 默认排除 |
| --- | --- |
| 文件名 | `autorun.inf`、`desktop.ini`、`Thumbs.db` |
| 目录名 | `System Volume Information`、`$RECYCLE.BIN`（含其它大小写写法）、`found.000`、`.Trash`、`.Trashes` |
| 文件后缀 | `*.tmp`、`*.part`、`*.crdownload`，以及你在配置里追加的后缀 |

> 后缀比较不区分大小写；追加的后缀会与默认后缀**合并**（默认项不能删除）。

### 安全策略

- **只复制，绝不执行**：不运行 U 盘里的任何 `exe`、`bat`、`cmd`、快捷方式或脚本，不做自动播放、不解析 `autorun.inf`（该文件本身就被排除）。
- 所有复制都是流式读写（1 MiB 缓冲区），大文件不会一次性占用大量内存。
- 目标目录若与源 U 盘在**同一个卷**（例如把 U 盘里的目录选作目标），程序会拒绝并跳过，提示「避免备份回 U 盘自身」。

### 为什么插入 U 盘不会自动备份（设计取舍）

这是**刻意的设计**，不是漏做：`UsbWatcher` 仍然监听插拔，但插入时只做三件事——弹一次气泡「检测到 U 盘」（提示你手动点「立即备份」）、写日志（其中一条明确写着「本工具不会自动备份，请在主界面点「立即备份」或右键托盘图标 →「立即备份」」）、更新主界面状态栏为「检测到 U 盘 X:，可点击「立即备份」」。

- 避免误插他人 U 盘就被自动整盘拷贝，造成隐私问题与磁盘占用。
- 备份时机完全由你决定：插好盘、确认内容后再点「立即备份」。

## 配置文件与日志

| 内容 | 路径 |
| --- | --- |
| 配置文件 | `%AppData%\WinToolBox\UsbBackup\config.json`（通常为 `C:\Users\<用户名>\AppData\Roaming\WinToolBox\UsbBackup\config.json`） |
| 日志目录 | `%LocalAppData%\WinToolBox\logs\`（通常为 `C:\Users\<用户名>\AppData\Local\WinToolBox\logs\`） |
| 日志文件 | `wintoolbox-yyyyMMdd.log`，按天切割，默认保留 30 天（启动时清理更早的日志，与 FolderCreator 共用同一文件） |

配置示例（`config.json`，只有这两个字段）：

```json
{
  "backupTargetDirectory": "D:\\UsbBackup",
  "excludedExtensions": [
    ".iso",
    ".tmp",
    ".part",
    ".crdownload"
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `backupTargetDirectory` | string | 备份目标目录；留空表示尚未配置，此时「立即备份」不会执行并提示先设置目标目录 |
| `excludedExtensions` | string[] | 排除的文件后缀（不区分大小写；可写 `.tmp` 或 `tmp`，保存时统一为小写并补 `.`） |

> **没有 `autoBackupEnabled` 之类的开关字段**：备份只能手动触发。旧版本配置里遗留的该字段会被直接忽略，点一次「保存设置」重写文件后它就会消失。
> 配置文件缺失、为空或损坏时，程序回退到默认配置并记一条 WARN 日志，**不会覆盖**你的原文件；在主界面点一次「保存设置」即可重新生成规范格式（手写时允许 `#` 注释与尾随逗号）。

## 命令行参数

```powershell
# 查看版本：输出形如 “WinToolBox - U盘备份 UsbBackup 0.1.0”
UsbBackup.exe --version

# 本机冒烟自检：在临时目录里跑一遍「首次复制 → 增量跳过 → 增量更新 → 排除规则 → 配置读写 → U 盘枚举」，
# 不依赖真实 U 盘；共 16 项检查，退出码 0 表示全部通过
UsbBackup.exe --selftest
UsbBackup.exe --selftest D:\selftest-report.txt   # 报告写到指定文件
```

- `--selftest` 不加路径时，报告写到 `%TEMP%\UsbBackup-selftest.txt`；终端里会同时打印报告全文（从资源管理器双击启动时没有控制台，只看报告文件即可）。
- 自检结论为「存在失败项」时退出码为 1，便于脚本判断。

## 常见问题

| 问题 | 原因与处理 |
| --- | --- |
| 双击后“没反应”，或托盘里看不到图标 | 先看任务管理器里有没有 `UsbBackup.exe`：**进程在 → 程序其实已经启动**。① 图标可能被 Windows 11 收进 **“^” 折叠区**，点开即可；② 到「设置 → 个性化 → 任务栏 → 其他系统托盘图标」把 UsbBackup 设为显示；③ 若菜单里能看到程序条目，右键 →「打开主界面」。 |
| 进程在运行但通知区域**永远**没有图标，且启动时弹过提示框 | 程序被以**低完整性**（沙箱 / 受限终端）启动，Windows 会拒绝它注册托盘图标。请先在任务管理器结束所有 `UsbBackup.exe`，再改用「在资源管理器里双击 `UsbBackup.exe`」或普通终端启动。 |
| 每次都弹 Windows 蓝色安全提示（SmartScreen） | 程序**未签名**，且文件带有“从网上下载”的来源标记。处理：右键 `UsbBackup.exe` →「属性」→ 勾选「解除锁定」→「确定」；解压后的整个目录可批量解除：`Get-ChildItem <解压目录> -Recurse -File \| Unblock-File`。长期方案是给 exe 做代码签名。 |
| 为什么插入 U 盘没有自动备份？ | **设计如此**：插入时只弹一次气泡提示、写日志、更新状态栏，备份必须手动点「立即备份」（见上文[设计取舍](#为什么插入-u-盘不会自动备份设计取舍)）。想确认的话可以在「运行日志」里搜索 `不会自动备份`。 |
| 点「立即备份」提示「没有检测到可移动磁盘（U 盘）」（通知标题为「未检测到 U 盘」） | 确认 U 盘已插好、在资源管理器里能看到盘符，再点「刷新设备」看「设备：N 个」是否大于 0；读卡器里没插卡、或盘符被其它软件占用时也会枚举不到。 |
| 点「立即备份」提示未配置目标目录 | 还没保存备份目标目录。到主界面「备份设置」里选择目录并点「保存设置」，再备份一次。 |
| 备份目录能不能直接选 U 盘自己？ | 不能。程序检测到目标与源在**同一个卷**时会跳过并提示「避免备份回 U 盘自身」，请改选本地硬盘上的目录。 |
| 备份汇总里出现「失败 K 个」 | 单个文件失败（权限不足、文件被占用、路径过长等）不会中断整轮备份。打开日志搜索 `失败明细` / `复制失败` 查看具体文件与原因，处理后重新点「立即备份」即可补上；已经复制成功的文件会被跳过。 |
