1. **用户完全不想保留原名时，没有替代方案** → 新增"完全替换原名"模式。
2. **Windows 隐藏扩展名导致用户认知偏差** → 预览列表强制显示完整文件名 + 检测系统设置并提示。
3. **删除/替换后空格残留** → 新增"自动清理多余空格"选项。
4. **扩展名处理不灵活** → 新增"扩展名处理"选项。
5. **预览列表列宽不可调，长名字被截断** → 预览列表支持列宽拖拽。

## 3. 功能需求

### 3.1 新增"完全替换原名"模式
在批量重命名界面顶部加一个模式选择器：

```
命名模式：  ● 基于原名修改   ○ 完全替换原名
```

**模式 A：基于原名修改**（现有行为，保持不变）
- 保留所有现有配置（删除、替换、前后缀、序号、日期）

**模式 B：完全替换原名**（新增）
- UI 切换为简化布局：
  ```
  新基名: [________]（留空则只用序号/日期）
  [✓] 添加序号  起始:[1] 位数:[3] 分隔:[_]
  [ ] 添加日期  格式:[yyyy-MM-dd▾] 来源:[修改时间▾]
  ```
- 生成逻辑：`新基名 + 分隔符 + 序号 + 分隔符 + 日期 + 扩展名`
- **边界情况**：
  - 新基名留空 + 只勾序号 → `001.txt`、`002.txt`
  - 新基名留空 + 只勾日期 → `2026-10-04.txt`（可能冲突，需要检测并提示）
  - 新基名留空 + 序号和日期都不勾 → 报错，提示"至少勾选一项或填写新基名"
  - 新基名非空 + 序号和日期都不勾 → 所有文件同名，冲突检测会拒绝执行

### 3.2 预览列表强制显示完整文件名
**"原名称"列永远显示完整文件名（含扩展名）。**

### 3.3 检测 Windows 隐藏扩展名并提示
**在用户打开批量重命名功能时，检测一次注册表**：

```csharp
using Microsoft.Win32;
var key = Registry.CurrentUser.OpenSubKey(
    @"Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced");
var hideExt = key?.GetValue("HideFileExt")?.ToString() == "1";
```

- 如果 `hideExt == true`，在预览区顶部显示警告横幅：
  ```
  ⚠ 您的 Windows 隐藏了文件扩展名。
     预览中显示的"原名称"是完整文件名（含扩展名）。
     如需在资源管理器中查看扩展名：查看 → 显示 → 文件扩展名。
  ```
- **只在进入批量重命名时检测一次**，不每次启动程序都检测。
- 用户关闭横幅后，本次会话不再提示。

### 3.4 新增"自动清理多余空格"选项
在"基础清理"区域加：

```
[✓] 自动清理多余空格
    ● 宽松模式（推荐）：合并连续空格为单个，去掉首尾空格
    ○ 严格模式：删除所有空格
    ○ 关闭
```

**处理逻辑**：
```csharp
string CleanSpaces(string name, CleanMode mode)
{
    return mode switch
    {
        CleanMode.Loose => Regex.Replace(name.Trim(), @"\s+", " "),
        CleanMode.Strict => Regex.Replace(name, @"\s+", ""),
        _ => name
    };
}
```

**执行时机**：在所有删除/替换操作**之后**，在拼接序号/日期/前后缀**之前**。

### 3.5 新增"扩展名处理"选项
在"主名重命名"区域加：

```
扩展名: [保留原扩展名 ▾]
        ○ 保留原扩展名（默认）
        ○ 统一改为 [ .txt ]（用户手输）
        ○ 删除扩展名
```

**默认保持"保留原扩展名"**，不改变现有行为。
